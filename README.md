# 🚑 Спаси Больного! — Скорая Помощь

Аркадный симулятор скорой помощи для Яндекс Игр: ночной город, вызовы, трафик,
бензин, прокачка машины, достижения, редкие скины, лидерборд и реклама SDK.

---

## ▶ Быстрый запуск (для всех)

Игра уже собрана в папку **`dist`**. Чтобы поиграть локально:

- **Windows** — двойной клик по файлу **`ЗАПУСТИТЬ ИГРУ.bat`**
  (браузер откроется сам; окно не закрывайте, пока играете)
- **macOS / Linux** — в терминале:
  ```sh
  chmod +x ./запустить-игру.sh && ./запустить-игру.sh
  ```
- **Если есть Node.js** — любой статический сервер:
  ```sh
  npx serve dist
  ```
  и открыть адрес, который покажет сервер.

> Почему не просто двойной клик по `dist/index.html`?
> Современные браузеры блокируют JS-модули с протоколом `file://`,
> поэтому игре нужен любой локальный сервер (кнопки выше делают это за вас).

Локально игра работает полностью, но **без рекламы и лидерборда** —
они включаются автоматически только на платформе Яндекс Игр.

## 📦 Загрузка в Яндекс Игры

> ⚠️ Отклонение «не найдено ни одного, либо найдено несколько index.html»
> означает, что в ZIP попало **несколько** файлов index.html. Так бывает,
> если заархивировать **всю папку проекта** (тогда внутри и корневой
> `index.html`, и `dist/index.html`). Яндекс требует **ровно один**
> `index.html` — **в корне архива**. Не архивируйте папку проекта вручную!

**Правильный способ — один клик:**

1. Соберите актуальную версию: `npm install`, затем `npm run build`.
2. Запустите **`СОБРАТЬ АРХИВ ДЛЯ ЯНДЕКСА.bat`** (Windows) или
   `./собрать-архив.sh` (macOS/Linux).
3. Скрипт упакует **только содержимое `dist`** в файл
   **`spasi-bolnogo-yandex.zip`** и **сам проверит**, что внутри ровно один
   `index.html` и лежит он в корне (та же проверка, что у модерации).
4. Загрузите получившийся ZIP в черновик игры в Консоли разработчика.

> Если архивируете вручную: выделите *содержимое* папки `dist`
> (`index.html`, `assets/`, `icon.svg`) и отправьте в ZIP именно их —
> не саму папку `dist` и не папку проекта целиком.

Дальше:
- **Иконка игры**: в проекте лежит `public/icon.svg` (попадает в `dist/icon.svg`).
  Консоль просит PNG 512×512 — откройте `icon.svg` в браузере и сохраните
  как PNG, либо используйте сгенерированный вариант:
  `https://image.qwenlm.ai/generated-images/096b7a5b-5138-4949-89bf-6f2cf438c445/_result.png`
- **Лидерборд**: в Консоли → Лидерборды → создайте лидерборд с техническим
  именем **`top_scores`** (по убыванию, тип «числовой»). Игра пишет туда
  итоговый счёт каждой смены автоматически.
- Скриншоты и описание заполняются в черновике (все тексты — в файле
  `ОПИСАНИЕ-ДЛЯ-ЯНДЕКС-ИГР.md`); язык игры — русский.

SDK подключён правильно: `/sdk.js` в `<head>` с `async` + `onload`,
инициализация `YaGames.init()` строго после загрузки скрипта.

## ✅ Аудит требований Яндекс Игр (что соблюдено в коде)

| Требование | Статус | Где в коде |
|---|---|---|
| `/sdk.js` в `<head>`, `async`, `onload`/`onerror` | ✅ | `index.html` |
| **Относительные пути ко всем ресурсам сборки** (`base: "./"`) | ✅ | `vite.config.js` — без этого JS-бандл 404-ит на CDN Яндекса и SDK «не встроен» (п. 1.1) |
| `YaGames.init()` только после загрузки скрипта | ✅ | `src/game/ads.ts` (ожидание событий + таймаут) |
| Методы SDK только после инициализации | ✅ | все обёртки ждут `initYandexSDK()` |
| `LoadingAPI.ready()` — когда игра реально готова (меню) | ✅ | `reportGameReady()` вызывается при показе меню |
| `gameplay.start()` / `gameplay.stop()` | ✅ | `App.tsx`: старт после загрузки, стоп на паузе/проигрыше/меню |
| События платформы `game_api_pause` / `game_api_resume` | ✅ | `engine.ts` — автопауза и возврат по сигналу платформы |
| Пауза + глухой звук при сворачивании вкладки | ✅ | `visibilitychange` / `blur` в движке |
| Звук полностью гаснет на время рекламы, возврат — строго в `onClose` | ✅ | `muteForAd`/`unmuteAfterAd` в `App.tsx` |
| Fullscreen-реклама между уровнями, не чаще 1 раза в минуту | ✅ | после каждой 3-й смены + клиентский кулдаун 60 с |
| Rewarded: награда только по `onRewarded`, без наложения окон | ✅ | флаг `granted`, окно кнопки сбрасывается до показа |
| Лидерборд: `isAvailableMethod`, устойчивость к гостям/офлайну | ✅ | `src/game/leaderboard.ts` |
| Сохранение прогресса (рекорд, баланс, достижения) | ✅ | `localStorage` + миграция старой версии |
| Никаких `alert`/`prompt`/`confirm`, внешних ссылок и сторонней рекламы | ✅ | — |
| Игра не ломается без SDK (локальный запуск) | ✅ | все SDK-вызовы имеют фолбэки |
| Иконка/фавикон | ✅ | `public/icon.svg`, подключён в `index.html` |

### Примечания (не блокируют модерацию, но полезно знать)

- **Язык**: игра на русском — это допустимо (основная аудитория платформы РУ).
  Если захотите международную раздачу — добавьте английскую локализацию строк.
- **Облачные сохранения** (`player.setData`) не подключены — рекорды хранятся
  локально. Это разрешено; при желании можно добавить поверх localStorage.
- Лидерборд `top_scores` нужно создать в Консоли до публикации,
  иначе блок «ТОП ИГРОКОВ» покажет аккуратную заглушку (игра не сломается).

## 🛠 Для разработчика

```sh
npm install      # зависимости
npm run build    # прод-сборка в dist
```

Структура:

```
src/game/engine.ts      — движок: физика, трафик, вызовы, больница, АЗС, ночь
src/game/world.ts       — процедурная генерация города
src/game/sprites.ts     — рисованные спрайты (скорая, пациенты, машины)
src/game/audio.ts       — WebAudio-синтезатор (сирена, гудок, касса…)
src/game/meta.ts        — прокачка, скины, достижения, сохранения
src/game/ads.ts         — обёртки Yandex SDK (init, реклама, gameplay, loading)
src/game/leaderboard.ts — лидерборд top_scores
src/ui/…                — меню, HUD, тач-управление, экран загрузки
```
